# arXiv_2305.05548_CIT-EmotionNet_CNN_Interactive_Transformer_Network_for_EEG

## 1. 论文全称

**CIT-EmotionNet: CNN Interactive Transformer Network for EEG Emotion Recognition**

中文可译为：

**CIT-EmotionNet：用于脑电情绪识别的 CNN 交互式 Transformer 网络**

作者：Wei Lu、Hua Ma、Tien-Ping Tan。

---

## 2. 核心创新点

1. **CNN 与 Transformer 并行建模**

   使用 CNN 提取局部空间特征，使用 Transformer 提取全局上下文特征，将两者统一到一个网络中。

2. **提出 CIT 双向交互模块**

   CIT 模块包含：

   * L2G（Local-to-Global）：将 CNN 局部特征注入 Transformer。
   * G2L（Global-to-Local）：将 Transformer 全局特征注入 CNN。

   不仅在网络末端拼接特征，而且在多个中间阶段进行双向交互。

3. **构建空间–频率 EEG 表征**

   将不同电极的五频带 PSD 特征按照电极空间位置排列，形成类似多通道图像的空间–频率特征图。

4. **获得较高识别精度**

   在 SEED 和 SEED-IV 上分别达到 98.57% 和92.09%的平均准确率。

---

## 3. 具体方法

整体处理流程如下：

1. 将连续 EEG 划分为互不重叠的 4 秒片段。

2. 对每个片段计算所有通道在 δ、θ、α、β、γ 五个频带上的 PSD。

3. 按照脑电电极在头皮上的空间位置，将各通道 PSD 映射为空间矩阵。

4. 将五个频带矩阵叠加，得到空间–频率表示。

5. 将该表示同时输入：

   * ResNet CNN 分支，提取局部特征；
   * ViT Transformer 分支，提取全局特征。

6. 在前三个阶段通过 CIT 模块实现局部与全局特征的双向融合。

7. 将最后一阶段的 CNN 特征与 Transformer 特征拼接。

8. 通过全连接层和 Softmax 输出情绪类别。

---

## 4. 模型结构

CIT-EmotionNet主要由三个部分构成：

### 4.1 CNN分支

采用ResNet结构，共5个阶段：

* Stage 0：`7×7卷积 + BN + ReLU + 3×3最大池化`
* Stage 1～4：每个阶段包含2个ResNet BasicBlock
* 输出局部特征：C1、C2、C3、C4
* 通道数逐渐增加为64、128、256、512

CNN分支主要提取局部空间结构和细粒度特征。

### 4.2 Transformer分支

采用ViT结构，共5个阶段：

* 输入空间–频率特征尺寸为`32×32×5`
* 将五个频带分别视为一个`32×32` Patch
* Patch数量为5
* 初始嵌入维度为256
* Stage 1～4各包含3个Transformer Encoder Block
* 每个Encoder包括：

  * 多头自注意力；
  * MLP；
  * Layer Normalization；
  * GELU和Dropout。

输出全局特征T1、T2、T3、T4。

### 4.3 CIT交互模块

CIT模块设置在Stage 1～3之间，包含两个方向：

* **L2G模块**：对CNN特征进行空间平均池化，再经过线性映射、维度扩展和拼接，将局部信息送入下一阶段Transformer。
* **G2L模块**：将Transformer特征进行维度变换和空间扩展，与CNN特征拼接，再使用`1×1`卷积融合，送入下一阶段CNN。

最后将C4和T4拼接，通过全连接层完成分类。

---

## 5. 数据预处理方法

论文使用的主要预处理和特征构建方法包括：

1. **信号分段**

   将原始EEG切分为互不重叠的4秒片段，每个片段继承原始试次的情绪标签。

2. **频域特征提取**

   提取五个频带的功率谱密度PSD：

   * δ频带
   * θ频带
   * α频带
   * β频带
   * γ频带

3. **空间电极映射**

   根据电极在头皮上的物理位置，将每个电极的PSD值映射到二维脑电电极位置矩阵。

4. **多频带叠加**

   将五个频带的二维矩阵沿通道维度叠加，构成`H×W×5`空间–频率表示，实际输入尺寸为`32×32×5`。

5. **数据集划分**

   样本随机打乱后，按照6:4划分训练集和测试集。

需要注意：论文主要描述了分段、PSD提取及电极空间映射，没有详细说明滤波、重参考、伪迹去除或标准化等原始EEG清洗操作。

---

## 6. 数据集及实验效果

论文在两个公开EEG情绪数据集上进行了实验：

| 数据集     | 分类任务 |   平均准确率ACC |    标准差STD | 对比结果 |
| ------- | ---: | ---------: | --------: | ---- |
| SEED    |  3分类 | **98.57%** | **1.38%** | 表中最优 |
| SEED-IV |  4分类 | **92.09%** | **5.33%** | 表中最优 |

与较强基线相比：

| 方法             |   SEED ACC | SEED-IV ACC |
| -------------- | ---------: | ----------: |
| EeT            |     96.28% |      83.27% |
| SST-EmotionNet |     96.02% |      84.92% |
| MD-AGCN        |     94.81% |      87.63% |
| CIT-EmotionNet | **98.57%** |  **92.09%** |

消融实验进一步表明：

* 仅CNN：SEED 74.36%，SEED-IV 50.93%
* 仅Transformer：91.77%，82.87%
* 仅末端拼接、不使用CIT：93.39%，87.81%
* 完整CIT-EmotionNet：**98.57%，92.09%**

这说明性能提升主要来自CNN与Transformer的联合建模，以及CIT模块在中间阶段进行的双向特征交互。



# arXiv_2511.15902_EEG_Emotion_Recognition_Through_Deep_Learning
## 1. 论文全称

**EEG Emotion Recognition Through Deep Learning**

中文译名：**基于深度学习的脑电情绪识别**。

作者：Roman Dolgopolyi、Antonis Chatzipanagiotou。

---

## 2. 核心创新点

* 将SEED、SEED-FRA和SEED-GER合并，构建包含中国、法国和德国受试者的多文化EEG情绪数据集。
* 将62个EEG电极减少至AF3、AF4、T7、T8和Pz五个电极，降低设备成本和计算量。
* 提出CNN-Transformer混合模型：CNN提取局部空间–频率特征，Transformer建模长时间依赖。
* 仅使用五个电极便获得约91%的三分类准确率，验证了消费级便携式EEG设备用于情绪识别的可行性。

---

## 3. 具体方法及模型结构

整体流程为：

`62通道EEG → 选择5个电极 → 五频带滤波 → 1秒分段 → 差分熵特征 → CNN → Transformer Encoder → 均值池化 → 情绪分类`

其中，CNN接收形状为`T×5×5`的差分熵特征，提取不同电极和频带之间的局部空间–频率特征；随后将CNN输出转换为嵌入序列，输入Transformer Encoder，通过多头自注意力学习不同时间窗口之间的长程依赖；最后经过Mean Pooling获得全局特征向量，并输出消极、中性和积极三种情绪。

最优模型参数为：

| 参数            |   最优设置 |
| ------------- | -----: |
| CNN输出通道数      |      8 |
| CNN卷积核        |      5 |
| Transformer层数 |      4 |
| 隐藏单元数         |    128 |
| 注意力头数         |      4 |
| 嵌入维度          |     64 |
| Batch size    |      8 |
| Dropout       |    0.1 |
| 学习率           | 5×10⁻⁴ |

---

## 4. 数据预处理方法

* 原始EEG采样率为200 Hz，共62个电极。

* 仅保留AF3、AF4、T7、T8和Pz五个电极。

* 将信号划分为连续的1秒时间窗口。

* 采用带通滤波提取五个频带：

  * δ：0.5～4 Hz
  * θ：4～8 Hz
  * α：8～13 Hz
  * β：13～30 Hz
  * γ：30～45 Hz

* 计算每个时间窗口、频带和电极信号的方差，并转换为差分熵（DE）特征。

* 最终每个试次构成`T×5×5`特征张量，分别对应时间窗口、频带和电极。

* 数据按照70%、15%、15%随机划分为训练集、验证集和测试集。该划分为受试者依赖划分，同一受试者可能出现在不同子集中。

---

## 5. 数据集及实验效果

研究合并了三个数据集，共得到1455个试次：

| 数据来源     | 国家  |  试次数 |
| -------- | --- | ---: |
| SEED     | 中国  |  675 |
| SEED-FRA | 法国  |  480 |
| SEED-GER | 德国  |  300 |
| 合计       | 多文化 | 1455 |

三类样本包括449个消极、513个中性和493个积极试次。最优模型在第89轮达到92.24%的验证准确率；测试集准确率为**90.82%**，宏平均F1为**92.22%**。

| 模型                  |      测试准确率 |   电极数 |
| ------------------- | ---------: | ----: |
| CNN-Transformer     | **90.82%** | **5** |
| SVM                 |     86.65% |    12 |
| DNN                 |     86.08% |    62 |
| Logistic Regression |     82.70% |    62 |

结果表明，该CNN-Transformer在论文设定下优于对比模型，并能在仅使用五个电极的情况下保持较高的情绪识别性能。

# arXiv_2411.00822_EEG-based_Multimodal_Representation_Learning_for_Emotion_Recognition
## 1. 论文全称是什么？

**EEG-based Multimodal Representation Learning for Emotion Recognition**

中文译名：**基于脑电的多模态表示学习情绪识别方法**。

作者：Kang Yin、Hye-Bin Shin、Dan Li、Seong-Whan Lee；arXiv编号为 **2411.00822**，2024年10月上传。

---

## 2. 论文的核心创新点是什么？

* 提出融合**脑电、音频和视频**的多模态情绪识别框架。
* 针对不同模态分别使用专门的Transformer提取器。
* 引入共享多头注意力模块，根据样本内容动态调整各模态的重要性。
* 模型能够处理不同尺寸、不同特征分布的异构输入。
* 在EAV数据集上建立多模态情绪识别基准，证明加入EEG能够补充音频和视觉信息。

---

## 3. 论文的具体方法和模型结构是什么？

模型采用“两阶段、多分支、注意力融合”结构：

1. **模态特征提取**

   * 视频帧输入Vision Transformer（ViT），提取视觉特征 (h_{vis})；
   * 音频转换为频谱图，输入Audio Spectrogram Transformer（AST），提取音频特征 (h_{aud})；
   * EEG时间信号输入EEGformer，提取脑电特征 (h_{eeg})。EEGformer包含一维逐通道CNN，用于处理多通道EEG。

2. **预训练阶段**

   三个模态的Transformer分别训练，使其学习各自模态的特征表示。

3. **多模态微调阶段**

   冻结三个预训练特征提取器，将三种特征展平、拼接后输入共享多头注意力模块，通过Q、K、V自注意力动态分配各模态权重。

4. **情绪分类**

   融合后的特征输入MLP分类器，识别愤怒、悲伤、中性、平静和快乐五种情绪；训练采用交叉熵损失。

---

## 4. 论文的数据预处理方法有哪些？

* **视频**：将视频划分为连续帧，再输入ViT。
* **音频**：将音频信号转换为时频谱图，再输入AST。
* **EEG**：以30通道时间序列形式输入EEGformer，由一维逐通道CNN进行通道级特征提取。
* 各模态特征在融合前进行展平和拼接。
* 论文表示实验沿用了EAV数据集原作者的预处理方法，但没有在正文中详细给出EEG滤波范围、重采样、伪迹去除和分段参数。

---

## 5. 论文在哪些数据集上取得了怎样的效果？

论文仅在**EAV数据集**上进行实验。该数据集包括42名受试者，每名受试者完成200次、每次20秒的交互实验，包含30通道EEG、视频和音频数据，其中音频仅包含100个说话阶段样本。

| 输入模态      |      平均准确率 |
| --------- | ---------: |
| 仅视频       |     67.22% |
| 仅音频       |     58.17% |
| 仅EEG      |     53.51% |
| EEG＋音频＋视频 | **70.86%** |

多模态模型比仅视频、仅音频和仅EEG分别提高 **3.64、12.69和17.35个百分点**。结果表明视觉模态单独表现最好，而融合EEG、音频和视频能够获得最高的整体识别准确率。
