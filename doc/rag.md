# 项目文档

## 技术可行性分析
    
### 行业数据

    主题 脑机接口与EEG解码（包含脑机接口系统，EEG情绪识别分类任务，EEG转文本等生成任务）

    数据来源：会议，期刊，arxiv上的期刊论文，关键字脑机接口，EEG

    目的：下载将近几年的相关领域的论文（具有高时效性和高知识密度），分段切成文本块 chunk 存储进知识库（LLM擅长处理文本信息）。

### RAG 知识检索

    RAG的原理详细介绍，常见方法简单介绍，需要说明 RAG 知识检索上述 EEG 知识数据的可行性。

## 技术细节

    知识库构建
        原理：
            详细介绍 RAG 项目是如何进行pdf提取，分段，二次分段...构建知识库的，
            详细介绍如何使用 embedding 模型构建向量库的
            详细介绍如何根据 query，基于BM25和向量余弦相似度，检索知识库和向量库，最后检索出 top_k 个最相关的文本段的。
        
        接口：
            详细介绍归档功能，指定一个论文pdf作为输入，程序将处理pdf内容，将chunk添加进知识库和向量库
            详细介绍检索功能，指定一个问题qeury，程序将根据qeury，从知识库和向量库中检索出最相关的 top_k 个结果并返回
            详细介绍 mcp 接口功能，建立 mcp 服务器将以上的归档，检索功能封装成 tools，提供给智能体，llm 能自主选择调用这两个工具。
